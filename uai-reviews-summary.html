Reviewer YTF7 — Rating: 6 (Weak Accept), Confidence: 4

Trajectory: Resolving Fig 1/Tab 3 contradiction + Anthropic SAE case study → 8; contradiction only → 7; unresolved → 5.

Summary: Frames metric failure as population-level misspecification (not finite-sample noise). Builds a factor-structure × encoder-geometry taxonomy, formalizes desiderata P1–P4, proves no metric satisfies all four, and gives a closed-form MCC failure under D_ρ + E3 (§F.1) plus a null-encoder bound E[MCC] ≳ √(2 log(m/n)) (§F.3).

Strengths

  • Novel framing: Metric failure as population-level misspecification rather than finite-sample noise / inductive bias. Orthogonal to Locatello et al. (2019) — shows that even supervised identifiability metrics are structurally misspecified under conditions identifiability theorems explicitly permit.
  • Tight theory–experiment coupling: §3.1 + §F.1 derive MCC's closed form under D_ρ + E3 (Eq. 18–44); Fig 2 visualizes the analytical prediction. §F.3 derives E[MCC] ≳ √(2 log(m/n)) for a null encoder via CLT + Hungarian-matching; Fig 5's heatmap independently verifies that m/n (not m/d) controls false-positive inflation. The m/n result is the most striking — names an evaluation-setting variable routinely exceeded in current mech-interp work.
  • Practical artifacts unusual for a formal paper: 10-item practitioner checklist (App A), metric × property truth table (Tab 3), explicit numerical thresholds for m/n and m/d (Tab 1).
  • Systematic survey: App C reviews 62 CRL / nonlinear-ICA papers (2020–2025, NeurIPS/ICLR/ICML/AISTATS/UAI/AAAI/CLeAR/JMLR). 25 used MCC, 9 used R², only 2 DCI — quantifies how widespread the misuse is.
  • Encoder taxonomy E1–E9: Spans every dimension-ratio regime (m=d, m<d, m>d incl. four overcomplete geometries + null baseline). Each has an analytic construction → reproducible without trained encoders.
  • Resistor-circuit running example (§2): R = R₀(1 + αT), V = IR — grounds abstract D_f / d_eff in physical intuition.

Weaknesses

  • Headline contradiction on R²'s P3 status: Fig 1 caption (p. 2) says "Only R² is robust across (P1), (P3), (P4)." Tab 3 (p. 8) marks R² × P3 as ✗. Fig 4 caption says "R² collapses for nonlinear E6" (a P3 failure). One of three takeaway sentences — if wrong, must be reframed as "no single metric satisfies P1, P3, P4 jointly" (strictly weaker positioning).
  • Tab 3 conflates two distinct MCC failures: §3.3 notes "MCC cannot be used for distributed codes (E8)" — a second failure mode under overcompleteness not flagged in Tab 3's MCC row (single ✗). Either clarify or split the row.
  • Only analytical encoders, no trained-encoder evidence: Acknowledged, but reviewers will ask first. Anthropic's Llama-3 / Claude-Sonnet SAEs have m ≈ 65k, n < 10k, so m/n ≥ 6.5 → §3.4 bound √(2 log 6.5) ≈ 2.16 (saturates MCC). Reported MCCs may be statistical floor effects.
  • MIG, InfoMEC, T-MEX appear only in Tab 3 + §G: §3 walks through only MCC, DCI-D, R². Two of these (InfoMEC, T-MEX) are 2023+ metrics rising in SAE evaluation — burying their failure cases leaves "no metric works" half-supported.
  • No impossibility lower bound for "no metric satisfies P1–P4." Even a sketch (e.g., must use higher-order moments / know d_eff / include null calibration) would convert this from negative survey into structural limit.
  • R²'s collapse on nonlinear E6 has no mechanistic explanation: Paper positions R² as "most robust"; Fig 4 shows it collapsing. §3.3 describes in one sentence with no algebra. §F should derive closed-form / asymptotic for R² under E6 in parallel to §F.1's MCC analysis.
  • §C 62-paper survey lacks methodological transparency: Semantic Scholar API mentioned, but not query strings, inclusion/exclusion criteria, dedup rules, inter-rater reliability. The 25/62 number is the headline motivating the paper.
  • Finite-sample → asymptotic transition in §3.4 lacks calibration: Text says √(2 log(m/n)) dominates for m/n ≳ 0.1 but no theory-vs-empirics relative-error table. For m/n < 1, log(m/n) is negative → bound undefined; yet Fig 5 sweeps to m/n = 0.01. Need continuation convention.
  • P1 + P4 interact under correlated factors: Null-encoder experiments assume ρ and m/n vary independently, but correlated GT factors drop effective dimension and change the constant in √(2 log(m/n)).
  • Definition 2: d_eff = d − k assumes independent constraints. Under multiple/non-independent constraints not well-defined.
  • Code release deferred to acceptance. OpenReview supports anonymous supplementary at submission — current stance reduces reproducibility unnecessarily.
  • Minor: Tab 2 caption has unfilled "[CITE]" for MIG (should be Chen et al. 2018). Tab 3 ✓/~/✗ undefined (e.g., "✓ ≥ 95% of settings, ~ 50–95%, ✗ < 50%"). p. 2 "MCC scaling in the order of √(2 log m/n)" should be "scales as √(2 log(m/n))." Fig 1 P3 panel caption should state GT identifiability holds throughout the m/d sweep (so upward MCC trend isn't read as real identifiability change).

Reviewer wGET — Rating: 7 (Accept), Confidence: 4

Scores: Novelty 3 | Correctness 3 | Evidence 3 | Reproducibility 3 | Writing 4 (Excellent)

Summary: Studies common evaluation metrics in identifiable representation learning and characterizes failure scenarios: correlated latents, redundancy from deterministic (causal) relationships, over-parameterized encoders, low representation-to-sample ratios. Each scenario gets desired property + synthetic empirical examples + (sometimes) theoretical justification.

Strengths

  • Important, often-overlooked problem: Whether commonly used metrics faithfully reflect identifiability. Analyzing failure cases from a novel perspective benefits the community.
  • Excellent writing: Well-structured, well-explained, clear notation, illustrative examples, highlighted takeaways.
  • Thorough empirical + theoretical analysis — generally well supports the claims and intuition.

Weaknesses

  • §3.2's "recover lossless part only" framing may not align with identifiable representation learning's goal. CRL aims to recover the full set of causal variables incl. graphical structure. Even in deterministic settings, latents carry semantic meaning → metric should arguably penalize missing variables more explicitly. Need to explain relationship between these two goals.
  • All empirical analysis on synthetic encoders — limits practical impact, leaves gap to real trained models (acknowledged).
  • No improved metric or design principles proposed beyond the practical checklist. The checklist assumes access to ground-truth info (e.g., latent dimensionality) often unavailable in practice — circular: if dimensionality is known, model design could already enforce structure, reducing need for evaluation guidelines.

  • Notation inconsistency: D1–D4 in Fig 3 title differs from main-text notation.
  • Clarify the relationship between "lossless recovery" goal and full causal-variable recovery (CRL goal).

Reviewer hjjj — Rating: 6 (Weak Accept), Confidence: 3

Scores: Novelty 3 | Correctness 3 | Evidence 3 | Reproducibility 2 (Fair) | Writing 3

Summary: Asks whether MCC, R², DCI actually measure recovery of GT factors. Shows they're trustworthy only under specific structural assumptions; otherwise systematic error. Contributions: DGP × encoder taxonomy, validity-domain characterization, reproducible stress-test suite, practitioner evaluation guideline.

Strengths

  • Important, under-explored problem: When can identifiability metrics be interpreted as meaningful evidence? Central in disentanglement / nonlinear ICA / CRL but often left implicit.
  • Clear, useful account of when/why metrics fail. Taxonomy cleanly separates DGP assumptions from encoder geometry; analysis makes existing-metric failure modes precise. Not just critical — provides structured understanding of metric validity.
  • Empirical study aligned with objective: Controlled constructions isolate metric behavior from optimization/implementation effects — right design for the question.
  • Well organized + easy to follow. Examples and takeaways chosen effectively. Practical-guidance appendix particularly useful — translates findings into concrete advice.

Weaknesses

  • Practical scope limited by absence of learned-encoder evidence. Synthetic-encoder analysis is intentional, but unclear when proposed geometries (esp. overcomplete ones) arise under realistic training dynamics.
  • Overcomplete encoder taxonomy stylized even at most complex (E8): Relies on disjoint-index constructions — useful for isolating failures but distant from general mixed/distributed code geometries that may occur in practice. E8 doesn't model many-to-many mappings (single latent → multiple factors).
  • Stronger as diagnosis than as resolution: Convincingly shows no existing metric is reliable across all settings, but practical outcome is taxonomy + stress-tests + cautionary guidance, not a concrete protocol or new metric.
  • Categories' necessity not justified by empirical observations on benchmark data (e.g., Shapes3D). Unclear under what conditions / inductive bias to expect the characterized behaviors.
  • Reproducibility weakened by deferred code release — controlled settings depend heavily on metric implementations (MCC, DCI-D, R²).
  • Notation collision: "n" used for both data generative process and number of samples.
  • Proposition 1 framing: Reads more like an example showing MCC failure than a generalizable claim — re-frame with explicit assumptions and quantitative relation.

TODOs / Questions

  • Extend E8 / overcomplete taxonomy beyond disjoint-index constructions to many-to-many mappings.
  • Re-frame Proposition 1 with explicit assumptions and quantitative relations.
  • Disambiguate notation for "n" (DGP vs sample count).
